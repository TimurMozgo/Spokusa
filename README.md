# SPOKUSA — perfume shop demo

Responsive Ukrainian-language perfume storefront demo with a ten-product catalog, three-image galleries, favorites, a cart, demo checkout and local order history.

## Run

Serve this directory using any static HTTP server. No build step or server credentials are required. GitHub Pages publishes the root of the `main` branch.

## Demo behavior

Orders and contact details are stored only in the visitor's browser using localStorage. Nothing is sent to the shop and no payments are collected. Prices, selectable volumes and store availability are illustrative. This is a presentation concept, not the store's official sales channel.

## Images

See `assets/SOURCES.txt` for source references and `assets/IMAGE-EDIT-NOTES.txt` for background-removal edits. The store-style catalog covers share one background; gallery images preserve the original product photography.

## Mobile layout

Two-column product grid, complete product names, aligned card footers, full-screen dialogs with a fixed close toolbar, touch galleries and safe-area spacing.
